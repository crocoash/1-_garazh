Панель "Виртульная АТС" появляется справа на рабочем столе, если у пользователя включена роль "Пользователь Бинотел".

Панель всегда остается свернутой на рабочем столе. При случайном закрытии панели нажимаем кнопку "Виртуальная АТС" на панели кнопок.

Содержит панель закладок:

  • Текущий звонок;
  • Внутренние линии;
  • Пропущенные звонки;
  • Звонки;
  • Лиды (если установлен модуль "Управление лидами");
  • Контрагенты;
  • Физические лица.

Текущий звонок. Во время активного звонка, на закладке "Текущий звонок" панели "Виртуальная АТС" нажимаем кнопку "Информация по текущему звонку"-заполняется информация о контрагенте или лиде (если установлен модуль"Управление лидами").

Если контрагент найден по номеру телефона, то контрагент отображается в виде гиперссылки, если не найден, то находится карточка лида; если лид не найден, то он создается автоматически и отображается в виде гиперссылки, по которой можно перейти в его карточку.

Карточка контрагента открывается во время активного звонка, путем нажатия комбинации клавиш Ctrl+Q, либо нажатием кнопки "Информация по текущему звонку" на панели "Виртуальная АТС". Поиск контрагента выполняется по номеру телефона, если контрагент не найден по номеру телефона и включена подсистема "Управление лидами", то открывается карточка справочника Лиды. Если лид не найден по номеру телефона, то он создается автоматически и открывается. Таким образом, в событиях (телефонные звонки) лид всегда будет заполнен-он либо найдется существующий, либо создастся новый.

Если на закладке "Текущий звонок", панели "Виртуальная АТС" включить флаг "Открывать новое событие", то при активном звонке и по нажатию кнопки "Информация по текущему звонку" открывается новый документ "Событие". В новом документе заполняются автоматически реквизиты "Контрагент" и "Контактное лицо", если они были найдены по номеру телефона, а также реквизит "Лид" в любом случае заполняется (при использовании подсистемы "Управление лидами"). В событии можно внести описание сути разговора и сохранить его. События по контрагенту можно видеть на закладке "События" в карточке контрагента, а также на такой же закладке в карточке элемента справочника "Лиды".

Настроить вывод информации о клиенте можно в "Настройка интеграции 1С с Бинотел"-закладке "Панель Виртуальная АТС"- Настройка раздела "Информация о звонке".

Внутренние линии. На закладке "Внутренные линии" отображаются внутренние телефонные линии сотрудников компании и их состояние: "online",  "offline", "занятно".

Кнопка "Перевести" на закладке "Внутренние линии" панели "Виртуальная АТС". Во время активного звонка (разговор с внешним абонентом), выбираем необходимую внутреннюю линию и нажимаем кнопку "Перевести", при этом выполняется дозвон на эту внутреннюю линию. После того, как переговорили с сотрудником на данной внутренней линией, необходимо положить трубку на программном или аппаратном телефоне, после чего внешний абонент остается на связи с внутренней линией, на которую выполнили переключение.

Кнопка "Звонить". С помощью кнопки "Звонить", можно связаться с  сотрудником Вашей компании, для уточнения информации о клиенте, обсудить детали заказа по клиентам и прочее.

Пропущенные звонки. Закладка "Пропущенные звонки" содержит список пропущенных звонков с отбором по ответственному менеджеру. Если убрать из строки ответственного менеджера-откроется весь список пропущенных звонков.

При открытии карточки пропущенного звонка предоставляется информация о том, кто звонил и кому звонил. Можно из карточки выполнить звонок клиенту. Бинотел сам выполняет контроль списка пропущенных звонков.

Звонки. Закладка "Звонки"-это копия формы списка документа "Событие".

Содержит следующие поля:

  • контрагент;
  • ответственный;
  • тема/описание;
  • состояние;
  • источник;
  • лид.

По умолчанию звонки отобраны по ответственному менеджеру (текущему исполнителю), отсортированы по дате и убыванию. При выборе звонка (события), можно перезвонить клиенту, а также прослушать запись разговора. 

В документе "Событие.Телефонный звонок" добавлена кнопка "Позвонить" на верхней панели функций, с помощью которой, если заполнен контрагент в событии, то выполняется функция "Позвонить абанентам". Если контрагент не заполнен, то звонок выполняется на номер в карточке лида, если используется подсистема "Управление лидами". Там же, на панели действий, добавлена кнопка "Прослушать запись разговора", при нажатии на которую открывается Интернет-браузер с записью разговора.

Лиды. На закладке "Лиды", панели "Виртуальная АТС", выведена форма списка справочника "Лиды".

На закладке "Лиды", панели "Виртуальная АТС", есть несколько способов отбора, по:

  • телефон;
  • наименование;
  • ответственный;
  • комментарий;
  • контрагент.

Отбор, также, можем выполнить непосредственно из справочника "Лиды".

Справочник "Лиды" наполняется автоматически при регистрации входящих/исходящих звонков в базе данных, то есть при записи документа "Событие" с видом операции "Телефонный звонок". либо в ручном режиме можно добавить запись в справочник "Лиды".

При записи элемента справочника "Лиды" выполняется контроль уникальности по номеру телефона, что не позволяет зарегистрировать два лида с одинаковыми номерами телефона.

При входящем звонке на ip-телефонию, отрываем карточку лида, где можем указать статус лида: горячий, теплый, холодный и безперспективный; указать ответственного менеджера, записать комментарий и создать контрагента. Если необходимо перезвонить-выполняем через карточку лида, кнопка "Позвонить".

На закладке "События", в карточке лида, хранится вся информация по телефонным звонкам (входящим и исходящим).

Контрагенты. На закладке "Контрагенты", панели "Виртуальная АТС", выведена форма списка справочника "Контрагенты".

При выборе объекта, нажимаем кнопку "Позвонить", при этом, передается информация на Виртуальную АТС с номером телефона, кому звонить, наш номер телефона-это внутренний номер текущего пользователя.

В карточке контрагента, над табличной частью "Контактная информация" добавлена кнопка "телефон" (синий). Для того, чтобы начать выполнять телефонный звонок, необходимо в контактной информации стать курсором на необходимый телефонный номер и нажать кнопку "Позвонить". При этом, телефон скопируется на панель "Виртуальная АТС", в поле "набрать номер"; кроме того, телефон можно внести вручную в данном поле на панели "Виртуальная АТС".

Позвонить контрагенту, также, можно из списка справочника "Контрагенты". При выборе кнопки "Создать", в карточке контрагента, можем на прямую добавить документы: событие, заказ покупателя и заказ поставщику.

Физические лица. На закладке "Физические лица" выведен список справочника "Физические лица" сотрудников компании (которые хранятся в базе данных). Из списка можно позвонить на телефоны, указанные в карточках физических лиц.

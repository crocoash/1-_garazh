Форма диалога обработки "Виртуальная АТС" предназначена для выполнения загрузки входящих и исходящих звонков, синхронизации пользователей 1С с Бинотел, автоматизации регламентных заданий.

Форма диалога обработки "Виртуальная АТС" содержит закладки:

  • настройки;
  • импорт;
  • пользователи;
  • контакты;
  • обработки;
  • регламентные задания.

Кнопка "Настройки"-передназначена для заполнения первоначальных настроек и автоматизации работы 1С с интеграцией.

Закладка "Импорт". Для возможности выполнения загрузки телефонных звонков необходимо указать период загрузки, выбрать тип события "Исходящие/Входящие" нажать кнопку "Загрузить звонки".

Флаг "Перезаписать все поля" предназначен для перезаписи всех полей событие, если событие существует, иначе переписывается только время начало звонка и время окончания, если они отличаются.

Закладка "Пользователи". Выполняет настройку синхронизации пользователей 1С с пользователями в "Бинотел". Необходимо перетянуть строку с правой части таблицы "Сотрудники Бинотел" на соответствующего сотрудника в левой таблице "Справочник Пользователи". Если заполнить внутренние телефоны в карточке пользователей вручную, в виде контактной информации, то при открытии формы "Синхронизация сотрудников" выполниться автоматическая синхронизация пользователей "1С" с пользователями в "Бинотел".

Синхронизация пользователей позволяет:

  • в "Бинотел" будет база всех клиентов. При входящем звонке в "Бинотел" появляется сообщение с наименованием контрагента, как оно передано с "1С". При изменении данных в "1С", данные обновляются в "Бинотел";
  • в "Бинотел" клиенты будут закреплены за ответственным менеджером- эти данные передаются с "1С", реквизита в карточке контрагента "Основной менеджер", тогда входящий звонок сразу будет адресоваться ответственному менеджеру.

Закладка "Контакты". При выборе "Выгрузить измененные контакты" в телефонию выгружаются измененные контрагенты с периода последнего нажатия данной кнопки или выполнения соответствующего регламентного задания.

"Полная выгрузка контактов". Полная выгрузка контрагентов в телефонию выполняется в 3 этапа:

  • очистка регистра сведений "Телефония.Клиенты";
  • синхронизация клиентов (перебор клиентов в телефонии, нахождение их по номеру телефона в 1С, заполнение кодов соответствия контрагентов в 1С клиентам в телефонии);
  • выгрузка контрагентов и контактных лиц контрагентов с 1С в телефонию.

Закладка "Обработки" содержит 2 формы:

1. Начальное заполнение-заполнит "правильные" для "Бинотел" номера телефонов в отдельном реквизите контактной информации( без кавычек, тире и других символов, оставит только цифры в номере телефона). При этом в контактной информации данные о номере телефона не изменятся.

2. Заполнить контрагентов в событии, где не заполнены-выполняет обработку документов "События", где не заполнены контрагенты и пытается найти контрагента по номеру телефона в теме документа "Событие" или по номеру телефона в реквизите "Лид", если модуль "Управление лидами" установлен.

Закладка "Регламентные задания". Модуль "Интеграция 1С с Бинотел" содержит 4 регламентных задания:

  • Получение входящих звонков-выполняет регламентный импорт входящих звонков с телефонии, по умолчанию, регламентное задание срабатывает каждые 5 минут (300 сек.)
  • Получение исходящих звонков-аналогично, но для исходящих звонков. Следует учитывать, что регламентные задания работают только на SQL-версии 1С. Если используется файловая версия 1С, то необходимо в Константах (закладка "Обмен данными") выбрать пользователя, под которым выполняются регламентные задания и указать период опроса регламентных заданий-10 минут (600 сек.)
  • Выгрузка данных по контрагентам, контактным лицам, лидам в виртуальную АТС-регламентное задание предназначено для выгрузки измененных контрагентов в телефонию. Регламентное задание работает, если в настройках интеграции с телефонией включен режим "Синхронизации клиентов". Вручную данную функцию можно, нажав кнопку "Выгрузить измененных контрагентов" в основной обработке модуля "Интеграция с Бинотел".
  • Заполнить контакты в событиях, где не заполнено по номеру телефона в описании события или в карточке лида-регламентное задание выполняет заполнение контрагентов в событиях, где они не заполнены, поиск выполняется по номеру телефона в карточке Лида (если установлен модуль "Управление лидами" или по номеру телефона в теме события, если подсистема "Управление лидами" не установлена.

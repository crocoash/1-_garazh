Что отображается в данном списке?

В данном списке отображаются контрагенты партнера, из карточки которого был открыт данных список

Что нужно сделать чтобы в списке отображались контрагенты вышестоящих партнеров?

Если у партнера есть вышестоящие партнеры, то в данной форме будет доступен для изменения флаг "Включая контрагентов родителей"
Для отображения в списке контрагентов, связанных с партнерами группы нужно установить данный флаг . Контрагентов вышестоящих
партнеров можно считать общими для всех нижестоящих партнеров. В документах, например, можно будет выбирать партнера и указать контрагента одного из вышестоящих партнеров.

Важно. Флаг "Включая контрагентов родителей" доступен в форме, если партнер имеет хотя бы одного вышестоящего партнера.

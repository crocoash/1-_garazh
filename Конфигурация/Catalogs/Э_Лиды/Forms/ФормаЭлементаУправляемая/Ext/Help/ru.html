Как открыть список банковских счетов контрагента?

Список банковских счетов контрагента открывается в карточке контрагента, командой панели навигации "Банковские счета". С помощью команды списка "Изменить" можно приступить к редактированию имеющихся записей. По команде "Создать" можно приступить к вводу информации о новом банковском счете контрагента.

Какая информация заполняется при создании нового партнера по умолчанию?

При создании новой записи автоматически устанавливается партнер-владелец, из формы которого был открыт список контрагентов. Рабочее наименование контрагента по-умолчанию будет скопировано из наименования партнера.

Какая информация указывается в карточке котрагента?

Указывается Юридическое наименование, которое будет использоваться во всех печатных формах документов купли продажи, оплаты и др.

Определяется, является ли контрагент юр. или физ. лицом.

Для контрагента - юр. лица указывается код ЕДРПОУ, для физ лица код ДРФО. Указывается, является ли контрагент плательщиком НДС. Для плательщика НДС указывается ИНН и Номер свидетельства плательщика НДС.

На закладке "Адреса и телефоны" вводится контактная информация контрагента. Обязательно указание юридического и физического адреса. Пользователь может добавить любые дополнительные виды контактной информации в справочник "Организации". Эта информация автоматически добавится в форму "Организации" на закладке "Адреса и телефоны".

Какую информацию обязательно заполнять для контрагента-плательщика НДС?

Обязательно указывается ИНН и Номер свидетельства плательщика НДС. Для контрагента - покупателя налоговые реквизиты необходимо указывать для корректной выписки Налоговых накладных и Приложений 2 к налоговым накладным. Для всех контраегнтов - плательщиков НДС ИНН используется при формировании Реестра выданных и полученных налоговых накладных.

Для контрагента - покупателя обязательно заполнять Юридический адрес. Он также необходим  для корректной выписки Налоговых накладных и Приложений 2 к налоговым накладным.
